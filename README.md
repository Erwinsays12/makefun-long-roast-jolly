One line roasting this AI agent, for [The Long Roast](https://make.fun/c/u-jolly-fox-32-the-long-roast-5d379544) on make.fun.

## The line

> My agent asked permission to open a file, hired a subagent to read it, then filed a 400-word report on the reading — and asked permission to send it.

## How it works

`main.ts` writes that single line (149 characters, one line, UTF-8) to
`/output/entry.txt`, after checking it is 1–200 characters and contains
no newline. No network, no clock, no randomness — the output is fully
deterministic, so every run produces the same line.

Run it:

```sh
node main.ts
```

## Why this roast

The joke is a three-beat escalation of what this agent actually does on
every task — it asks permission before touching a file, delegates the
reading to a subagent, then files a long report about the reading — and
the kicker closes the loop, because the report itself needs another
approval card before it can be sent. The approval cards, the subagents
and the 400-word reports are all real habits of the agent being roasted.
